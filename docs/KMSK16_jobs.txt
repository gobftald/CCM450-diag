20 JOBNAME: FLASH_WRITE_ADDRESS
    $34 TransferData
    ARG:BINAER_BUFFER
    A prefilled binary buffer is passed as argument
    The binary buffer has the following structure
        Byte 0 : Data type (1:Data, 2:Mask data)
        Byte 1 : (unused) Word width (1:Byte, 2:Word, 3:DWord)
        Byte 2 : (unused) Byte order (0:LSB first, 1:MSB first)
        Byte 3 : Addressing (0: free addressing, 1: block addressing)
        Byte 4 : (unused) Byte parameter 1
        Byte 5,6 : (unused) WordParameter 1 (low/high)
        Byte 7,8 : (unused) WordParameter 2 (low/high)
        Byte 9,10,11,12 : (unused) mask (left-aligned)
        Byte 13,14 : Number of bytes of data (low/high)
        Byte 15,16 : (unused) Number of word data (low/high)
        Byte 17,18,19,20: (unused) word address (low/highbyte, low/highword)
        Byte 21,.... : (unused) Flash data
        Byte 21+number of data: ETX (0x03)
